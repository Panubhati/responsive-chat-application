
# 💬 Responsive Chat Application

A full-stack responsive real-time chat application built with **React**, **Firebase**, and **REST APIs**. Users can sign up, log in securely, and chat in real-time across devices.

## 🚀 Features

- 🔐 **Firebase Authentication** – Secure login and sign-up
- 💬 **Real-time Chat** – Powered by Firestore
- 📱 **Responsive UI** – Works across all screen sizes
- 🌐 **REST API Integration**
- 🌓 Light/Dark Mode (Optional if implemented)

## 🛠️ Tech Stack

- **Frontend**: React, HTML, CSS, JavaScript
- **Backend**: Firebase (Authentication + Firestore)
- **Deployment**: Vite (or CRA), Firebase Hosting / Netlify / Vercel
